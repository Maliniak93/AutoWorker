# Product

## Vision

AutoWorker is a self-hosted web application that automates the owner's day-to-day work with Claude. It replaces a collection of loose scripts with one app that manages the production of code for the owner's other applications, and runs on a WSL instance or any other machine the owner controls.

## The problem we solve

Work with Claude is currently driven by separate scripts: there is no single place to start, watch, repeat and review that work.

## Users

The owner — a single developer running it on their own machine. No multi-user or public deployment is planned.
